## Continuation handoff - 2026-10-26 (Cloud Files tag check in Rust copy planner)

API research found a supported explicit hydration primitive: `CfHydratePlaceholder` hydrates a specified file byte range and accepts an `OVERLAPPED` for asynchronous calls; on `ERROR_IO_PENDING`, Microsoft documents waiting with `GetOverlappedResult`. It requires `READ_DATA` or `WRITE_DAC` and `CF_HYDRATE_FLAG_NONE`. This changes the local placeholder cache, so it must be treated as a user-visible download even though it does not change folder settings or source content. The API documentation does not establish that the current `FILE_FLAG_OPEN_REPARSE_POINT` hash handle can safely read the hydrated bytes, nor does it define our cancellation contract. `CfOpenFileWithOplock` returns an opaque handle that standard Win32 file APIs cannot consume directly; using a converted Win32 handle requires a protected-handle reference, a short bounded access window, and a matching release. Do not retain the referenced handle across a whole-file hash or close it with the wrong API. Before changing the planner, prototype file identity checks, supported handle usage, bounded asynchronous range hydration/read, and cancellation with a disposable Cloud Files provider; then verify actual iCloud behavior in an isolated environment. Do not expose the route in the Rust UI yet. Sources: [CfHydratePlaceholder](https://learn.microsoft.com/en-us/windows/win32/api/cfapi/nf-cfapi-cfhydrateplaceholder), [CfOpenFileWithOplock](https://learn.microsoft.com/en-us/windows/win32/api/cfapi/nf-cfapi-cfopenfilewithoplock), [CfGetWin32HandleFromProtectedHandle](https://learn.microsoft.com/en-us/windows/win32/api/cfapi/nf-cfapi-cfgetwin32handlefromprotectedhandle), [CfReferenceProtectedHandle](https://learn.microsoft.com/en-us/windows/win32/api/cfapi/nf-cfapi-cfreferenceprotectedhandle), [CfReleaseProtectedHandle](https://learn.microsoft.com/en-us/windows/win32/api/cfapi/nf-cfapi-cfreleaseprotectedhandle), [Cloud Files placeholder behavior](https://learn.microsoft.com/en-us/windows/win32/cfapi/build-a-cloud-file-sync-engine).
